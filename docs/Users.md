# Users of SM EventAura

## 1. Admin
The business owner (your father).

Responsibilities:
- Manage decorations
- Manage bookings
- Manage consultations
- Manage inventory
- Manage rental items
- Generate quotations
- Track payments
- View reports

---

## 2. Customer

Responsibilities:
- Browse decoration gallery
- Search decorations
- Upload inspiration images
- Book consultations
- Request quotations
- Confirm bookings
- Track booking status
- View payment status

---

## 3. Staff (Future)

Responsibilities:
- View assigned bookings
- Update inventory
- Assist during events
